# Security Policy

Проект в ранней разработке; поддерживается только ветка `main`.

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue**. Используйте приватный канал GitHub:
**Security → Report a vulnerability** (GitHub Security Advisories) в этом репозитории.

Укажите: что затронуто, шаги воспроизведения, возможное влияние. Секреты и персональные данные в отчёт не вкладывайте.

Мы стараемся ответить в течение нескольких дней; после исправления договоримся о раскрытии.
