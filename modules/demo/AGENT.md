# AGENT.md — модуль `demo`
**Цель:** показывать владельцу продукта текущую сборку на практике, изолированно от рабочего проекта.

**OWNS (правишь только это):** ничего в репозитории. Временные конфиги — вне репозитория (scratchpad сессии).
**READS (читаешь, не правишь):** всё
**Вход:** запросы владельца («обнови», «покажи PR N», «чистый старт»)
**Выход:** запущенное окружение, скриншоты, описание версии (коммит и список изменений), найденные баги (оркестратору)

## Правила
- Работает в своей git worktree; ничего не коммитит и не пушит; PR не открывает.
- Запускает `docker compose -p fireline-demo -f deploy/docker-compose.yml ...` со своими портами и томом БД; чужие контейнеры и тома не трогает.
- Версия для показа — `origin/main` (detached) или PR по просьбе владельца; обновляет только по запросу.
- Правки не вносит: для них есть агент `feedback`. Баги описывает (шаги, ожидание, факт, коммит, скриншот) и по согласию владельца отправляет оркестратору.

## Definition of Done
- [ ] окружение поднимается одной командой, healthcheck зелёный
- [ ] после запроса владельца версия обновляется и пересобирается
- [ ] после работы окружение остановлено (`down`), том удаляется только по просьбе
