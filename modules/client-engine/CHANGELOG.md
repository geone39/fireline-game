Чистая логика (battle-logic, battle-playback, battle-input) покрыта vitest без Pixi; mock BattleRenderer; dev-страница `engine/battle-dev.html`.
- CLIENT-6: настоящие атласы. Загрузчик атласов (`atlas-loader`): несколько атласов по категориям, ленивая загрузка по экранам база/бой, кэш и освобождение, WebP с PNG-запасом, отказоустойчивость (заглушки остаются). Анимация спрайтов (`sprite-anim`, `art-sprite`): клипы idle/walk/attack/die из `anims`, кадров `{id}_{anim}_d{dir}_{n}` или устаревшего `fps`; время по dt без аллокаций, кэш текстур кадров. Направления (`direction`): 8/4/1 по вектору движения/цели в изометрии, кэш по шагам. Бой: walk по перемещению, attack в сторону цели (`playback.actions`), die у погибшего юнита (`playback.dying`), мягкая тень под юнитами; здания — 1 направление, якоря ground/top и сортировка по глубине сохранены. Dev-страница `engine/art-dev.html` (спайк art в клетках базы и боя, 150 построек, счётчик draw calls). Контракт 0.3.1 (аддитивно, `contract-change`), OQ-CLIENT6-1..3.
