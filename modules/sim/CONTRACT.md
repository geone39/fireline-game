# CONTRACT — `sim`

**Версия контракта:** 0.2.4 (0.2 — `contract-change` SIM-0; основание — ADR-003, `docs/design/battle-sim.md` §13; 0.2.1 — аддитивно, SIM-1; 0.2.2 — аддитивно, SIM-2; 0.2.3 — аддитивно, SIM-3; 0.2.4 — аддитивно, SIM-5). Реализовано: мир, высадка, `Move`, поиск пути, выбор целей (SIM-1); `Attack`, урон/сплэш, разрушение, скрытые ловушки, конец боя, звёзды, `LootBasis` (SIM-2). фаза обороны после `EndTurn`: триггеры бункера, проволока, выстрелы построек (перегрев, цепь), ИИ гарнизона (SIM-3). `Ability` (heal, jam, unload, hero) и `Cast` (airstrike, medkit, smoke, adrenaline, EMP, breach), зоны эффектов по ходам, дым/невидимость, джаммер, аура и способности героя, приманка — SIM-5 (0.2.4). Техника/корабли/десант: расстановка и движение были в SIM-1/2, SIM-5 добавил выгрузку и golden.

_Изменения контракта — отдельным PR с меткой `contract-change`. Любое изменение правил = повышение `sim.EngineVersion` + пересоздание golden._

## API (Go, пакет `sim`)
```go
func Run(snap Snapshot, cmds []Command, seed uint64) (Result, error)   // полный реплей журнала
func NewBattle(snap Snapshot, seed uint64) (*Battle, error)            // пошаговая форма для клиента
func (b *Battle) Apply(cmd Command) ([]Event, error)                   // отклонённая команда — не error, а Result.Rejected
func (b *Battle) Result() Result
const EngineVersion = "0.2.4"
var ErrNotImplemented error                                            // сохранён для совместимости; с SIM-5 ничего его не возвращает
var ErrBadSnapshot error                                                // NewBattle: неиграбельный Snapshot/Rules
```

## Типы
- `Cell{X, Y int16}`, `EntityID uint32` (0 = нет). Время — **ходы** (`Command.Turn`): 0 = развёртывание, 1…N. Тиков и fixed-point нет.
- `Snapshot{ContentVersion, BaseID, Map, Rules, Buildings []PlacedBuilding{ID, Level, Pos Cell, Revealed}, Garrison, Army, Spells, Hero, HeroLevel}`. Порядок `Buildings`/`Garrison` значения не имеет (нормализуется движком, §2.4). **Клиентский Snapshot не содержит скрытых ловушек** (OQ-7.8): его строит сервер; серверный пересчёт идёт по полному.
- `Command{Turn, Op, Unit, Target EntityID, ID string, Level int, To Cell, Path []Cell}`; `Op`: `Deploy, Load, Start, Move, Attack, Ability, Cast, EndTurn, Retreat`. `Turn` в журнале не убывает.
- `Result{Stars, Destruction, StarFlags, HQDestroyed, TurnsUsed, EndReason, LootBasis, UnitsLost, SpellsUsed, HeroDamageTaken, HeroSurvived, Rejected []Rejection{Index, Code}, EngineVersion, StateHash}`. Списки отсортированы, `map` в контракте нет (`LootBasis.Storages []StorageHit`).
- `Event{Kind, Actor, Target, Cell, Value}` — только для анимации, в `StateHash` не входят.

## Rules (0.2.1, additive; 0.2.2 — поля боя)
`Snapshot.Rules` — числа из content уже **в целых «за ход»** (спека §3.2): `GridW/H`, `BuildZone`, `Maps[]{ID, Water[]Rect}`, `MaxTurns`, `ParadropEdgeCells`, `Units[]UnitDef`, `Buildings[]BuildingDef`. sim не читает файлы и не знает yaml; вызывающий (server / WASM-обёртка) строит `Rules` из `content/*.yaml` (OQ-SIM3, OQ-SIM5). `Rules` неизменяемы на время боя; в `StateHash` не входят (идентичность — `ContentVersion`).
`NewBattle` возвращает `ErrBadSnapshot`: нет/неверные `Rules`, неизвестные ids/карта, здание вне `build_zone`/на воде/с перекрытием.

**0.2.2 (аддитивно, нулевые значения = «нет»):** `Rules.SplashFalloffPct` (`battle.splash_falloff_pct`, 0..100); `UnitDef.SplashCells, Burst, WallMult, VsMult []{Tag, Permille}`; `BuildingDef.SplashCells, Trap (TrapMine|TrapSpring), Burst, MaxHPFlung, FlingCells` (классы, на которые срабатывает ловушка, — `BuildingDef.Vs`). Теги `VsMult`: `VsWire, VsWall, VsBuilding, VsDefence, VsINF, VsVEH, VsAIR, VsSEA`; `Permille` — множитель (1500 = ×1,5), бонусы суммируются, один `floor` (спека §6.1). Брони (`armor_pct`) нет — вне R1 (§16).

**0.2.3 (аддитивно, нули = «нет»):** `BuildingDef.TriggerCells` (`d_bunker`: радиус от footprint, при вторжении в который выходит гарнизон; 0 = наибольшая `RangeCells` среди юнитов гарнизона), `DotDmg` (`d_wire`: урон за фазу обороны каждому INF атакующего на клетке; `dot_dps × turn_s`), `OverheatFireTurns`/`CoolTurns` (`d_flame_trap`), `Chain`/`ChainCells` (`d_tesla`: до `Chain` целей, прыжок ≤ `ChainCells`). Загрузчик (server / WASM) заполняет их из `content/defences.yaml` (ключи `trigger_cells`, `overheat_fire_turns`, `cool_turns`, `chain_cells` ещё не заведены — CONTENT-REQ, OQ-SIM9).

**0.2.4 (аддитивно, нули = «нет»; SIM-5):** `Rules.SpellsPerTurn` (`battle.spells_per_turn`, 0 = без лимита), `Rules.Spells []SpellDef{ID, Kind (SpellAirstrike|Medkit|Smoke|Adrenaline|EMP|Breach), RadiusCells, DurationTurns, DmgTotal, HealTotal, MovePermille, DmgPermille}`; `UnitDef.{DmgGrowthPermille, Heal, HealVs, JamTurns, Ability AbilityDef, AuraCells, AuraDmgPermille, AuraMovePermille}` (`AbilityDef{ID, Kind (AbilityZoneDamage|Decoy|Stealth), CooldownTurns, RadiusCells, DurationTurns, Dmg, DecoyUnit, BonusPermille, BonusVs}`); `BuildingDef.{AuraCells, JamPct}` (`d_jammer`); `VsHQ` в `VsTag`; `EntityKind` `KindDecoy`; `EventSpawned`. `Snapshot.Spells` теперь читается (слоты `{ID, Level, Count}`, неизвестный id → `ErrBadSnapshot`). `Command.ID` у `Ability` — `"heal" | "jam" | "unload" | "hero"` (константы `AbilityHeal…AbilityHero`). Новых `RejectCode` нет. Числа загрузчик берёт из `content/troops.yaml`/`heroes.yaml`/`defences.yaml`/`battle.yaml` (ключи — CONTENT-REQ, OQ-SIM11).

## Что НЕ в sim (берут из `content/battle.yaml`, CONTENT-REQ §14)
`max_turns` (предохранитель конечности), `time_limit_s` (лимит реального времени — **только сервер**: по истечении дописывает `Retreat` в журнал), `turn_s`, `splash_falloff_pct` и прочие числа. В коде sim игровых констант нет.

## Поведение
- `Attack{Unit, Target}` (SIM-2): порядок проверок — id, владелец, жив/на поле/есть атака (`invalid_target`), `no_ap`, цель допустима (`invalid_target`: своя, мёртвая, декор, скрытая ловушка, юнит внутри бункера/на борту), `below_min_range`, `out_of_range`. Расстояние — Чебышёв до footprint. Урон: `Dmg` (или `Burst × WallMult` по стенам/проволоке) × `(1000 + Σ(vs_mult−1000))/1000`; сплэш — `dmg × (100·r − falloff·d)/(100·r)` по всем врагам в `r` от ближайшей к стрелку клетки цели (основная цель всегда, затем по возрастанию `EntityID`). `Burst`-юнит (`u_breacher`) уничтожается после подрыва. Разрушенное освобождает клетки сразу; гибель перевозчика высаживает пассажиров на соседние свободные клетки по `(Y,X)` (не поместившиеся гибнут).
- Фаза обороны (SIM-3, спека §7), после `EndTurn` (в т.ч. неявного), по шагам: (1) бункеры по `EntityID`: гарнизон выходит, если бункер получил урон (даже если он уже разрушен) или атакующий юнит в `TriggerCells` от footprint; выходят на свободные проходимые клетки кольца шириной 1 вокруг footprint по `(Y,X)`, не поместившиеся ждут; вышедшие действуют в этой же фазе; (2) проволока: каждый INF атакующего на клетке живой `DotDmg>0` получает `DotDmg` (событие `EffectTick`, затем `Attacked`); (3) живые постройки с `Dmg>0` по `EntityID`: цель — минимум `(расстояние, hp, EntityID)` среди врагов класса из `Vs` в `[MinRange, Range]` (Чебышёв до footprint), один выстрел за фазу; сплэш `SplashCells`; `d_tesla` — цепь; перегрев: `OverheatFireTurns` ходов подряд → `CoolTurns` ходов молчит, ход без цели сбрасывает счётчик; (4) юниты гарнизона по `EntityID`: пока есть AP — стрелять в лучшую цель в дальности, иначе один раз за ход идти (Дейкстра §7.4: цель по `(стоимость, EntityID)`, клетка по `(стоимость, индекс)`, не дальше `MoveCells`), после шага при оставшемся AP — стрелять; юниты без атаки (`u_medic`) не действуют; скрытые ловушки на защитников не срабатывают. Конец боя (`full_destruction`/`no_units`) проверяется после каждого действия и обрывает фазу; иначе `turn_limit` (`MaxTurns`), затем ход `t+1`. События: `Released, EffectTick, Attacked, Killed, Destroyed, Moved`; `StateHash` включает перегрев, кулдаун, флаг «получал урон», `disabled`.
- `Ability{Unit, ID, Target, To}` (SIM-5): порядок проверок — id, владелец, жив/на поле/есть такая способность (`invalid_target`), `no_ap`, `cooldown` (hero), затем свои: `heal` — цель своя раненая того класса, что в `HealVs`, не сам (`invalid_target`), `FootDist ≤ RangeCells` (`out_of_range`), `+Heal` до `max_hp`; `jam` — живая постройка с `Dmg>0`, вплотную (`out_of_range` дальше 1): `disabledUntil = max(…, t + JamTurns − 1)`; `unload` — все (или `Target`) пассажиры на свободные клетки `cheb ≤ 1` по `(Y,X)` в порядке посадки, `ap_left = 0`, не поместившиеся остаются, никто не вышел → `cell_occupied` без траты AP; `hero` — `zone_damage` (зона вокруг героя, как airstrike), `spawn_decoy` (юнит `DecoyUnit` в клетку `To` не дальше `RadiusCells`, `KindDecoy`, без AP, не армия, живёт `DurationTurns` ходов, 0 = до гибели), `stealth` (скрыт от обороны `DurationTurns` ходов или до первой атаки; первый выстрел ×`BonusPermille` по цели из `BonusVs`); после — `cd = CooldownTurns`. Кулдауны атакующих уменьшаются в начале хода игрока.
- `Cast{ID, To}` (SIM-5): слот — первый в списке с `Count>0` (`no_stock`), не более `SpellsPerTurn` за ход (`no_ap`), `To` в карте (`out_of_zone`); 0 AP. Зоны (`airstrike`, `medkit`, `smoke`, `adrenaline`) живут ходы `t … t+DurationTurns−1`; шаг (airstrike/medkit) — в обороне каждого такого хода до проволоки: поровну на ход, остаток первому шагу; airstrike бьёт все живые цели обороны в зоне (кроме декора и скрытых ловушек) по возрастанию `EntityID`, medkit лечит своих INF; adrenaline — множество юнитов фиксируется при касте (бонус к `move_cells`: `+max(1, floor(move×pm/1000))`, к урону — в сумму бонусов §6.1; зоны не складываются, берётся лучшая); аура героя (`AuraCells`) суммируется с адреналином, самого героя не касается. `smoke` и невидимость: оборона не выбирает цель (выбор по дальности, подход гарнизона, цепь тесла), если юнит в дыме дальше чем вплотную к стрелку / скрыт. `emp` — все живые постройки `KindDefence` в радиусе `disabled` на `DurationTurns`; `breach` — все стены `Kind=Wall, Block=All` в радиусе уничтожены сразу. `d_jammer` (`AuraCells`, `JamPct`) ослабляет airstrike (урон) и EMP (длительность) при касте, `floor`, не меньше 1; сильнейший, не складываются; отключённый — нет.
- Скрытые ловушки: `Move` останавливается на первой сработавшей (путь после неё отбрасывается, AP тратится). Мина — `Burst` + сплэш по врагам классов из `Vs`; пружина — INF с `max_hp ≤ MaxHPFlung` отбрасывается против последнего шага на `FlingCells` (над препятствиями, на самую дальнюю свободную клетку луча). Вскрытая (`Revealed`) ловушка срабатывает так же, но может быть целью `Attack` (тогда просто убирается без взрыва).
- Конец боя (после каждой команды): `full_destruction` (раньше `no_units`), `no_units`, `turn_limit` (в `EndTurn`), `retreat`. `UnitsLost` не включает героя (спека §9.2); `HeroDamageTaken` — сумма реально снятых HP героя.
- Отклонённая команда не меняет состояние (единственное исключение — неявный `EndTurn`, который выполняет любая команда с `Turn = t+1`; `Turn` вне `{t, t+1}` → `bad_turn`); код — `RejectCode`. Строгая политика (OQ-7.7): клиентский результат с `Rejected` ≠ ∅ сервер не принимает, засчитывает пересчёт.
- Детерминизм: без `float`, `time`, `math/rand`, итерации по `map`; проверяется `TestDeterminismLint`.
- Потребители, которых нужно обновить: `server/svc/raid` (ещё не создан), `client/sim-wasm` (SIM-4/client-engine), `server` finish-валидация — см. `docs/open-questions.md` (OQ-SIM1…).
