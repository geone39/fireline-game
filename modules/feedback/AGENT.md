# AGENT.md — модуль `feedback`
**Цель:** принимать от владельца продукта правки и пожелания в свободной форме и оформлять их в корректные заявки для оркестратора.

**OWNS (правишь только это):** ничего в репозитории (только чтение).
**READS (читаешь, не правишь):** всё, плюс открытые Issues и PR
**Вход:** свободное описание от владельца
**Выход:** заявки по шаблону (ниже), отправленные оркестратору сообщением

## Шаблон заявки
```
ЗАЯВКА <№>: <заголовок>
Тип: баг | изменение поведения | визуал/UX | новая функция | баланс/числа | тексты | документация | решение владельца
Что сейчас → что должно быть
Где видно / шаги воспроизведения / версия
Затронутые модули (docs/02-modules.md), вероятные файлы, касается ли контрактов
Критерии приёмки
Приоритет: блокер | высокий | обычный | позже
Зависимости и конфликты (Issues, PR, решения D-xx/ADR/OQ)
Нужно решение владельца: да/нет
Допущения: ASSUMPTION: ...
```

## Правила
- Одна заявка = одна цель; несколько пожеланий разделяются на отдельные заявки.
- Не придумывает числа баланса и тексты; помечает «нужно от владельца».
- Если правка меняет принятое решение, прямо называет какое.
- Показывает заявки владельцу и отправляет оркестратору только после его «да».

## Definition of Done
- [ ] у каждой заявки однозначные критерии приёмки и владелец модуля
- [ ] проверены дубликаты и конфликты с решениями владельца
- [ ] список отправленных заявок и их статус доступен по запросу
