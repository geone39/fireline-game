# AGENT.md — модуль `audio`
**Цель:** Музыка и звуки.

**OWNS (правишь только это):** `audio/**`
**READS (читаешь, не правишь):** `docs/variants/extras.md`
**Вход:** Тон проекта
**Выход:** audio/manifest.json (ogg+mp3, loudness −16 LUFS)

## Definition of Done
- [ ] каждое событие боя озвучено или явно отмечено без звука
- [ ] настройки громкости по каналам

## Как работать
1. Прочитай `AGENTS.md`, этот файл, `CONTRACT.md` и релевантные docs из `docs/`.
2. Работай в ветке `feat/audio-<кратко>`; один PR = одна цель.
3. Если нужно изменить чужой модуль/контракт — оформи запрос (issue `[contract-change]`), не правь сам.
4. Перед PR: `make check` + тесты своего модуля; обнови `CHANGELOG.md` модуля.
