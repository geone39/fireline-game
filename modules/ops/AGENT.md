**Цель:** CI/CD, окружения, мониторинг, бэкапы.

**OWNS (правишь только это):** `deploy/**`, `.github/**`, `docs/runbooks/**`
**READS (читаешь, не правишь):** всё
**Вход:** Теги
**Выход:** Образы, окружения, дашборды

## Definition of Done
- [ ] staging автодеплой с main
- [ ] RPO 5 мин проверен
- [ ] алерты на ошибки/задержки/экономические аномалии

## Как работать
1. Прочитай `AGENTS.md`, этот файл, `CONTRACT.md` и релевантные docs из `docs/`.
2. Работай в ветке `feat/ops-<кратко>`; один PR = одна цель.
3. Если нужно изменить чужой модуль/контракт — оформи запрос (issue `[contract-change]`), не правь сам.
4. Перед PR: `make check` + тесты своего модуля; обнови `CHANGELOG.md` модуля.
