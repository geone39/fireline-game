- ART-1 (#125, спайк): `art/STYLE.md` (стиль A01-lite, палитра P01+P03, размеры, слои, анимация, атласы, лимиты, юр. чистота); `art/spike/` — два пути рендера тестовых ассетов `b_hq`, `b_cash_mine`, `u_rifleman` (Node-процедурный 4 напр. и Blender 8 напр.) из общих `models.json`+`palette.json`, атласы, манифесты, `preview.html`, `COMPARISON.md` с рекомендацией; `art/tools/merge_spike.py`. `art/manifest.json` и контракт не менялись (запрос расширения — OQ-ART1-1)
- ART-2 (#140, фундамент массового производства, без производства контента): структура `art/src/<категория>/` (terrain, decor, buildings, defences, units, vehicles, ships, heroes, spells_fx, ui) с `models.json` и сгенерированной частью `manifest.part.json`; единая палитра `art/src/palette.json`; единый сборщик `art/tools/build_art.py` (Blender по `BLENDER_EXE`/PATH/стандартным путям Windows или процедурный Node; кадры -> атласы по категориям WebP q90 + PNG; детерминированная сборка `art/manifest.json` из частей; `--category`, `--id`, `--preview`, `--templates`, кэш по хэшу входов); рендереры `art/render/blender_render.py` и `proc_render.mjs` (на базе спайка, кадры по файлам); `art/tools/check_art.py` (id = content, якоря, кадры, атлас <= 2048, бюджеты первая загрузка < 3 МБ / полный < 40 МБ, хэш входов, актуальность manifest/CATALOG, шаблоны); `art/tools/gen_catalog.py` -> `art/CATALOG.md`; `art/tools/assemble.py` (пересборка manifest/CATALOG без рендера для слияний); образцы `art/templates/models.json` по одной модели на категорию; `art/README.md`, `art/src/README.md` (установка Blender, сборка одной сущности, добавление категории, именование, формат моделей). 69 заглушек собираются новым пайплайном с тем же контрактом манифеста (поля, кадры, якоря, fps; атласы `vehicles`/`ships` отдельно от `units`). Удалены `gen_placeholders.py` (-> `placeholder.py`), `check_manifest.py`, `merge_spike.py` (заменены пайплайном). Манифест расширяется только аддитивно (`dirs`, `anims`, `webp`) — предложение контракта 0.2 отдельным коммитом, OQ-ART2-3. Запросы: OQ-ART2-1 (ops: `make art-check`, CI), OQ-ART2-2 (приоритеты M1-M3), OQ-ART2-3, OQ-ART2-4.
