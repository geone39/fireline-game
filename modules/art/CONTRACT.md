# CONTRACT — `art`

art/manifest.json: {id, atlas, frames[], anchors, fps} — ID совпадает с id из content.

_Изменения контракта — отдельным PR с меткой `contract-change`; версия контракта указывается ниже._

## Расширение 0.2 (аддитивное, ПРЕДЛОЖЕНИЕ — ждёт утверждения владельца, OQ-ART2-3)

Обратно совместимо: поля 0.1 не меняются, потребитель 0.1 новые поля игнорирует. Заглушки (спрайты без модели) остаются в формате 0.1.

- Спрайт, собранный из модели, дополнительно содержит `dirs` (1 | 4 | 8; 0 = лицом к камере, далее по часовой стрелке на экране) и `anims`: `{имя: {fps, frames, loop}}`, `frames` — кадров на одно направление. Имена кадров: `{id}_{anim}_d{dir}_{n}`; статика: `{id}_0` (+ `{id}_damaged_0`, `{id}_ruin_0`). `fps` на уровне спрайта остаётся (fps анимации `walk`, иначе 0).
- Атлас дополнительно содержит `webp` — путь к WebP (качество 90); `image` (PNG) остаётся обязательным фолбэком.
- Манифест собирается из частей `art/src/<категория>/manifest.part.json` скриптом `art/tools/build_art.py` (формат частей — внутренний, не контракт); руками `art/manifest.json` не правится.

**Версия контракта:** 0.1 (0.2 — предложение, вступает в силу после утверждения)
