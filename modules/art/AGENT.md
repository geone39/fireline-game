# AGENT.md — модуль `art`
**Цель:** Визуал по утверждённому стилю.

**OWNS (правишь только это):** `art/**` (включая скрипты генерации в `art/tools/`)
**READS (читаешь, не правишь):** `docs/variants/DECISIONS.md`
**Вход:** Выбор A/P/U
**Выход:** Атласы, спеки, manifest.json

## Definition of Done
- [ ] все спрайты по спеке размеров
- [ ] читаемость силуэтов на 48px
- [ ] лицензии ассетов в art/LICENSES.md

## Как работать
1. Прочитай `AGENTS.md`, этот файл, `CONTRACT.md` и релевантные docs из `docs/`.
2. Работай в ветке `feat/art-<кратко>`; один PR = одна цель.
3. Если нужно изменить чужой модуль/контракт — оформи запрос (issue `[contract-change]`), не правь сам.
4. Перед PR: `make check` + тесты своего модуля; обнови `CHANGELOG.md` модуля.
