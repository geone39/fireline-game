# Fireline («Плацдарм») — ранняя разработка

> ⚠️ **Ранняя разработка.** Проект в активной работе: API, контент и баланс меняются без предупреждения, готового к игре релиза пока нет. «Fireline» — рабочее кодовое имя, «Плацдарм» — рабочее название (проверка товарного знака впереди).

Браузерная стратегия в жанре base-builder: строишь базу, обучаешь армию, нападаешь на чужие базы (асинхронно) и на ботов в сюжете. Название, сеттинг, графика и правила — **свои**; мы не копируем ни одну существующую игру.

## Состав
- `sim/` — детерминированное боевое ядро (Go, собирается в WASM; сервер и клиент считают бой одинаково)
- `server/` — авторитарный API (Go, PostgreSQL)
- `client/` — браузерный клиент (TypeScript)
- `content/` — все игровые числа и тексты (`*.yaml` + JSON-схемы в `content/schema/`)
- `modules/` — брифы и контракты по доменам, `docs/` — проектная документация, `tools/` — валидация контента и симулятор экономики, `deploy/` — docker compose и образы

## Быстрый старт
Нужны: Docker, Go (версия из `server/go.mod`), Node 22, Python 3 (`pip install pyyaml jsonschema`).
```
docker compose -f deploy/docker-compose.yml up --build   # postgres + сервер + dev-клиент
make check            # контент + экономика + go test + клиент (lint/typecheck/test/build)
python3 tools/econ_sim.py
```
Без `make` (Windows) — см. `docs/runbooks/dev-checks.md`. Переменные окружения — `deploy/ENV.md`. Пароли в compose — только для локальной разработки.

## Как устроена работа
Проект ведут ИИ-агенты под управлением владельца: один агент — один модуль, контракты важнее реализации, числа живут только в `content/`, боевое ядро детерминировано. Правила: [`AGENTS.md`](AGENTS.md), роль оркестратора: [`ORCHESTRATOR.md`](ORCHESTRATOR.md), вклад: [`CONTRIBUTING.md`](CONTRIBUTING.md). Продукт и решения: `docs/00-vision-and-decisions.md`.
