# art/STYLE.md — гайд по стилю A01-lite (палитра P01 + P03)

Статус: ART-1 (спайк), версия 0.1. Решения владельца (`docs/variants/DECISIONS.md`): сеттинг S01 (современная операция, тропики, береговые карты), стиль **A01-lite** (изометрия 2.5D, мягкая обводка, спрайты из 3D-моделей, меньше направлений и упрощённые модели; запасной — A03, плоский вектор), палитра **P01** (оливковый + песочный + оранжевый акцент) и **P03** (ржавчина + лазурь) для береговых карт, UI — U03 (глянцевые кнопки) + U01 (металл, заклёпки), тон ироничный.

Числа в этом файле — художественные (пиксели, кадры, цвета), игровых чисел здесь нет (AGENTS.md п.3). Эталон исходников — `art/spike/` (модели `models.json`, палитра `palette.json`, два рендерера).

## 1. Принципы

1. **Читаемость важнее детали.** Юнит должен узнаваться по силуэту на 48 px в реальном размере, здание — по крыше и характерному «акценту» (башня, колесо, флаг).
2. **Мало, но чётко.** Крупные формы, 3 ступени света, одна обводка. Мелочь ≤ 2 px не рисуем.
3. **Ирония в деталях, не в пропорциях.** Чуть крупная голова/каска, толстые «мультяшные» конечности, бочки и мешки — главные «шутки». Реализм — не цель.
4. **Всё своё.** Формы, цвета, силуэты, названия — наши; ориентиры — жанр и сеттинг, не конкретная игра (см. §10).

## 2. Проекция и размеры

| Параметр | Значение |
|---|---|
| Проекция | диметрия 2:1, камера: азимут 45°, высота 30° над горизонтом, ортографическая |
| Тайл | ромб **64×32 px** (`art/manifest.json → spec.tile_px`) |
| Мир → экран | `sx = (x − y)·32`, `sy = (x + y)·16 − z·39.19` (ребро тайла = 1 по x, y и z; 39.19 = 32·√2·cos 30°) |
| px на единицу вдоль экранных осей | 32·√2 = 45.2548 → `ortho_scale = max(w, h)/45.2548` в Blender |
| Свет | сверху-слева экрана; вектор «к свету» в осях сетки `(−0.3, 0.5, 0.8)` (в `palette.json`) |
| Юнит | кадр **48×48**, якорь `ground` = (24, 43), рост ≈ 34 px (0.85 ед.), ширина корпуса ≈ 12 px |
| Здание | ширина `(fw+fh)·32`, высота `(fw+fh)·16 + H`, H — запас над ромбом (штаб в спайке: 176×256-кадр при H = 48); якорь `ground` = центр футпринта на земле (`x = w/2`, `y = H + (fw+fh)·8 − 1`) |
| Герой / крупная техника | кадр 64×64 (пока `unit_frame_px` = 48 для всех; смена — отдельным `contract-change` после решения по OQ-ART1-2) |
| Максимум высоты здания | геометрия не должна выходить за кадр: у заднего угла ромба запас всего H px, у центра — до `(fw+fh)·8 + H` (рендереры спайка печатают `WARN`, если вышла) |

Мастер-рендер делается с суперсэмплингом ×4 и сжимается в 1× (в Blender — тем же скриптом). ASSUMPTION: в R1 поставляется только 1×; при необходимости retina — мастер уже можно сохранить в ×2.

## 3. Палитра

Единственный источник — `art/spike/palette.json` (sRGB). Ключи и роль:

| Группа | Ключи | Применение |
|---|---|---|
| P01 основа | `olive_dark #3f4b2b`, `olive #5f7040`, `olive_light #8a9b55` | форма, униформа, крыши, трава-союзник |
| P01 песок | `sand_light #eadfb4`, `sand #d6c38c`, `sand_dark #a8935c` | стены, мешки, рюкзаки, площадки |
| P01 акцент | `orange #ea7424`, `orange_dark #b3501a` | **только** акценты: нарукавная повязка/команда, флаги, бочки, колесо шахты, дверные козырьки, интерактивное. ≤ 8 % площади спрайта |
| Нейтрали | `steel #6f787d`, `steel_dark #3b4247`, `concrete #a6a296`, `earth #6b5238`, `skin #e0b48c`, `gold #e3b13a` | металл, оружие, бетон, грунт, кожа, ресурс «деньги» |
| P03 берег | `rust #a8552f`, `rust_dark #6a3220`, `azure #31a7b8`, `glass #2c7f94`, `foam #d9f1ee` | береговые карты: ржавчина построек, вода, окна/стекло, пена |
| Обводка | `outline #2a2418` | единственный цвет контура (не чёрный: тёплый, мягче на песке) |

Правила цвета:
- **Юнит ≤ 6 цветов** + обводка (спайк: olive_dark, olive, olive_light, sand_dark, steel_dark, skin; акцент orange 1 деталь). **Здание ≤ 8 цветов** + обводка.
- Три ступени света (cel): блик ×1.0, средняя ×(0.86, 0.88, 0.94), тень ×(0.66, 0.70, 0.84) — тень **холодная** (сдвиг в синий), не просто тёмная. Пороги по `n·L`: ≥ 0.65 / ≥ 0.25 / ниже. Верх всегда в блике, левый борт — средняя, правый — тень.
- Фон карты — насыщенный средний зелёный/песок; спрайты **светлее и контрастнее** фона по значению (яркости), поэтому земля не использует `olive_light` и `sand_light`.
- Цвет стороны (союзник/враг): не перекраской формы, а **акцентом** (нарукавная повязка, флаг, полоса на крыше) — одна заменяемая палитра-маска «team», оранжевый по умолчанию. Режим дальтоников (`docs/01-architecture.md §7`) добавляет форму метки (круг/квадрат), а не только цвет.

## 4. Силуэт, обводка, свет

- **Силуэт на 48 px.** Проверка: уменьшить кадр до реального размера и закрасить в один цвет — юнит должен читаться по форме. Различаем классы по трём признакам: каска/головной убор, оружие, ранец. Пехота — вертикальная, техника — широкий низкий прямоугольник, корабль — вытянутый клин, герой — на 15–20 % выше юнита и с «подписным» предметом (плащ, шляпа, флаг).
- **Обводка.** Внешний контур 1.0 px у юнитов, 1.6 px у зданий (в 1×), цвет `outline`. Внутренние линии: 0.5–1 px, цвет = заливка × 0.55, только на стыке деталей/верха и бока (Blender: обводка inverted hull без внутренних линий, допускается freestyle-линия для сгибов). Толщина не зависит от зума — контур запекается в спрайт.
- **Свет.** Один источник (вектор в §2), без теней-по-кадру: cel-ступени по нормали. Падающая тень на землю: у юнита мягкое пятно-эллипс (≈ 20×10 px, чёрный 25–28 %), у здания — свою тень «запекает» площадка/основание, отдельного пятна нет.
- **Сглаживание.** Детали ≥ 2 px; изогнутые поверхности — 12 сегментов и сглаженные нормали (Blender) или 12-гранная призма (процедурный).
- **Не использовать:** градиенты, текстуры-фото, шум, блюр, бликов-спеков, чёрный `#000`.

## 5. Слои

Порядок отрисовки клиента (снизу вверх), у каждого слоя свой атлас/набор:

1. **Земля**: тайлы, декаль-пятна, вода/берег (P03), сетка редактора.
2. **Тени-пятна** (если не запечены).
3. **Постройки и юниты** — один слой с сортировкой по `y` якоря; препятствия и декор той же сортировкой.
4. **Подсветки/маркеры**: футпринт, радиус, выбранный, команда.
5. **FX**: вспышки, дым, взрывы, попадания, всплески — отдельный атлас `fx`, без обводки, аддитивный/альфа, ≤ 8 кадров, 12–16 fps; в спрайты юнитов FX не запекаются.
6. **UI** (HUD, окна) — стиль U03/U01, отдельный документ.

## 6. Анимация

| Анимация | Кадров | fps | Цикл | Примечание |
|---|---|---|---|---|
| `idle` | 2 | 3 | да | «дыхание»: смещение корпуса ≤ 1 px по вертикали |
| `walk` | 4 | 10 | да | контактные позы ног на 1 и 3 кадре, подъём корпуса 2 px |
| `attack` | 3 | 8 | да | прицел → отдача → возврат; вспышка — FX |
| `die` | 4 | 8 | нет | оседание, последний кадр — лежит на земле (держать в пределах 48×48: падаем «от камеры») |

- **Направления:** юнит/герой — **8** (0 = лицом к камере, далее по часовой стрелке на экране: S, SW, W, NW, N, NE, E, SE); второстепенные (декор-NPC, дальние корабли) — 4. Здание — 1 направление; состояния: `normal`, `damaged` (< 50 %), `ruin` (отдельный кадр).
- Кадры нумеруются `{id}_{anim}_d{dir}_{n}`; здания — `{id}_0`, состояния — `{id}_damaged_0`, `{id}_ruin_0`.
- Позы описываются в данных (`models.json`: группы + повороты вокруг пивота), а не рисуются кадр за кадром — так анимации одного рига переиспользуются.
- Уровни зданий: визуально различаются **ярусами** (L1–3, L4–6, L7–10 …) — добавлением деталей на тот же корпус, не новым силуэтом; детали считаются и здесь «акцентом» (≤ 8 % оранжевого).

## 7. Атласы и формат

- Источник правды остаётся `art/manifest.json` (`{id, atlas, frames[], anchors, fps}` — контракт `art` 0.1) + TexturePacker-JSON рядом с каждым атласом.
- Состав: `units` (пехота), `vehicles`/`ships` (отдельно, т. к. кадры шире — решает OQ-ART1-2), `heroes`, `buildings`, `defences`, `decor`, `spells`, `fx`, `ui`. Правило: **атлас ≤ 2048×2048**, степень двойки, зазор между кадрами 1 px (2 px, если клиент масштабирует не кратно).
- Формат поставки: **WebP** (качество 90, `method 6`, альфа) как основной; PNG — исходный/отладочный (в репозитории лежат PNG спайка). По замеру спайка WebP q90 в 1.3–2.4 раза меньше PNG (юнит 8 направлений: 113 → 47 КБ). Цвета — straight alpha, sRGB. Пайплайн: PNG → webp на этапе сборки клиента (клиент владеет сборкой — запрос в OQ-ART1-3).
- Первая загрузка: только `ui`, `buildings` (штаб, склады, шахты текущего уровня), `units` казармы L1; остальное — ленивая подгрузка по главам.

## 8. Лимиты производительности

| Лимит | Значение | Как соблюдаем |
|---|---|---|
| Первая загрузка | < 3 МБ (`docs/01-architecture.md §7`) | весь спайк (юнит × 104 кадра + 2 здания) в WebP = 56 КБ; бюджет 3 МБ — запас на порядок, остальное лениво |
| Полный набор | < 40 МБ | оценка на 360 листов в `art/spike/COMPARISON.md` |
| Draw calls | < 150 за кадр | один слой = один атлас, сортировка по атласу внутри слоя; не более 8 одновременных атласов; частицы — пул |
| FPS | 60 на смартфоне 2021 | кадров на юнита ≤ ~110 (8 нап.), спрайты без полупрозрачных больших площадей |
| Память GPU | ≤ 64 МБ на атласы одной сцены | 2048² RGBA = 16 МБ: не более 4 больших атласов одновременно |

## 9. Производство и контроль качества

1. Модель в `art/src/<категория>/models.json` (или `.blend` → glTF, позже) → `art/tools/build_art.py` (рендер, атласы, манифест) → `art/tools/check_art.py`; подробности — `art/README.md` (ART-2).
2. Чеклист ассета: силуэт читается на 48 px; ≤ 6/8 цветов; контур замкнут; свет сверху-слева; якорь на земле; кадр не обрезан; ширина здания = `(fw+fh)·32`; лицензии записаны в `art/LICENSES.md`.
3. DoD модуля `art` (`modules/art/AGENT.md`): все спрайты по спеке размеров, читаемость на 48 px, лицензии.

## 10. Юридическая чистота

- **Не копируем референс.** Референс-ролик геймплея браузерной игры жанра base-builder — только за жанр/сеттинг/угол камеры. Запрещено: трассировка или реконструкция кадров ролика, повтор формы/расцветки/композиции его зданий и юнитов, интерфейсных элементов, названий, иконок, звуков и текстов. Перед релизом — проверка товарного знака (OQ-5, рабочее имя «Плацдарм»).
- **Свои модели.** Всё, что в репозитории, сделано нами: процедурно или в Blender из примитивов. Выход рендера принадлежит проекту (лицензия Blender не накладывается на изображения).
- **Сторонние материалы** (3D-паки, текстуры, шрифты, звуки) — только CC0 / CC-BY / SIL OFL / сопоставимые, с записью строки в `art/LICENSES.md`: файл, автор, URL, лицензия. CC-BY — только с указанием в «Об игре». NC/ND/неизвестные — нельзя.
- **ИИ-генерация** — только как референс/мудборд и только с согласия владельца; в рендер-пайплайн, атласы и финальные ассеты не попадает. Если владелец разрешит иное — отдельная запись в `docs/open-questions.md` и в `LICENSES.md`.
- Шрифты UI: пока не используем (в спайке нет текста вне dev-превью, системный шрифт).
