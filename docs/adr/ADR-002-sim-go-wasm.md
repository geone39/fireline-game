# ADR-002 Боевое ядро — Go, WASM на клиенте
Статус: принят. Решение: `sim` — чистая библиотека без I/O, собирается в `GOOS=js GOARCH=wasm` (или TinyGo при размере >1.5 МБ). Сервер импортирует тот же пакет. Риск: размер/скорость WASM — бенчмарк-гейт в CI; запасной вариант — TinyGo либо порт ядра в Rust по тому же набору golden-реплеев.
