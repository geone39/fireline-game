# ADR-003 Модель боя
Статус: предложен (ждёт OQ-1). Вариант A (рекомендуется): детерминированный realtime с фиксированным шагом 100 мс; атакующий выпускает юнитов по ходу боя. Плюсы: «как CoC», зрелищность, простой реплей (журнал команд). Вариант B: ходовой — атакующий действует по раундам; плюсы: проще мобильный ввод, дружелюбнее новичкам; минусы: медленнее, менее динамично, иной UX. Правила (урон/цели/ИИ) общие; различие в планировщике (`sim.Scheduler`). Решение откладывается до M2, интерфейс sim не зависит.
