# ADR-001 Модульный монолит на Go
Статус: принят. Контекст: малая команда, потребность в чётких границах. Решение: один бинарь, пакеты `svc/*` с интерфейсами; БД одна, но таблицы принадлежат своему сервису (чужие читать нельзя). Последствия: простой деплой, легко выделить сервис позже. Альтернатива (микросервисы) отклонена: издержки на ops.
