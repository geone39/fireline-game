# Пакет вариантов на одобрение

Как пользоваться: в каждом файле у вариантов есть ID. Отметьте в `DECISIONS.md` — `✅ допустимо`, `🟡 возможно/с правками`, `❌ убрать`. Можно комбинировать (сеттинг × стиль × палитра). Пока выбора нет, код использует `name_key` и серые плейсхолдеры.

Файлы: `settings.md` (12 сеттингов с названиями ресурсов/юнитов), `names.md` (40 названий игры), `art-styles.md` (10 стилей + палитры + UI), `world-hooks.md` (сюжет, фракции, персонажи, события), `extras.md` (звук, мета-фичи, косметика, режимы).
Чтобы выбор не тормозил разработку: см. «Минимальный выбор» в `DECISIONS.md` — 4 галочки достаточно, остальное можно позже.
