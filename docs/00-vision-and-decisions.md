# 00. Видение и принятые решения

## Продукт в одном абзаце
Игрок командует укреплённым плацдармом. Он добывает ресурсы, строит оборону (заборы, проволока, пулемёты, миномёты, ловушки), обучает армию (пехота, техника, корабли, герои) и нападает на базы других игроков и ботов. Его базу тоже могут атаковать — пока он офлайн; бой считается автоматически по сохранённой раскладке защиты. Успех атаки — до 3 звёзд (штаб = 1 звезда, 50% разрушения = 1, 100% = 1).

## Решения (ADR-кратко; полные в `docs/adr/`)
| ID | Решение | Почему |
|---|---|---|
| D-01 | **Браузер — основная платформа** (PWA, мобильный и десктоп). VK/Telegram позже как адаптеры (`client/platform/`). | Быстрая итерация; один билд; адаптеры изолируют платформенные правила |
| D-02 | **Асинхронный PvP как в классических стратегиях с атаками на базы**: нападающий сражается с ИИ-защитой сохранённого снимка базы; защитник не участвует и не блокируется. Две стороны не бьются одновременно. | Нет онлайна/лобби; масштабируется; нет ожидания |
| D-03 | **Модель боя (OQ-1, решено 2026-10-19): пошаговый тактический бой на клеточной сетке.** Атакующий каждый ход командует своими юнитами (стрелять или двигаться), ходы обороны (постройки, подкрепление) делает ИИ. Детерминизм сохраняется. | Выбор владельца по референсу; лучше ложится на мобильный ввод. См. ADR-003 (принят) |
| D-04 | **Ядро боя на Go**, компилируется в WASM для клиента и используется сервером для проверки реплея. | Один код правил = ноль расхождений |
| D-05 | **Сервер авторитарен**: ресурсы, награды, лут, кубки считаются сервером. Клиент шлёт команды боя + журнал. | Античит |
| D-06 | **Кампания против ботов** = тот же движок, раскладки пишутся вручную. Платит ×1.6, но ограничена энергией (~3 этапа/день) и растит затраты (армия тратится). | Замедляет прогресс осознанно |
| D-07 | **Контент в YAML** + схемы + валидатор; числа не в коде. | Агенты правят баланс без кода |
| D-08 | **Чёткие модули** (`docs/02-modules.md`) с контрактами; один агент = один модуль. | Параллельная работа |
| D-09 | Экономика: 3 мягких ресурса + премиум; калибровка скриптом `tools/econ_sim.py`. | «Не много и не мало» проверяемо |
| D-10 | Название/сеттинг/графика — по утверждённому варианту из `docs/variants/`. До утверждения везде `name_key`/плейсхолдеры. | Контент не блокирует разработку |

## Что значит «пошаговый» (решено, OQ-1)
Игрок на своём ходу даёт каждому юниту одно из действий: выстрелить по зданию или юниту обороны, либо переместиться по клеткам. Затем ходит ИИ обороны: постройки и гарнизон действуют сами (как в играх этого жанра, защитник их не контролирует). Правила (урон, цели, ИИ) общие и детерминированы; время боя измеряется ходами, а не тиками. Детали механики — OQ-7 в `docs/open-questions.md`.
