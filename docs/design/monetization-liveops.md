# Монетизация и LiveOps (R1 — черновик)
Принципы: платёж ускоряет, но не покупает победу; цена gems привязана к ускорению. 
Товары: пачки gems (5 уровней), боевой пропуск (дорожки free/premium), «стартовый набор» (одноразовый, ограничен по времени), косметика (скины зданий/юнитов/декор), 6-й билдер.
Площадки (позже): VK (голоса/VK Pay), Telegram (Stars для цифровых товаров) — через `PlatformAdapter.purchase`; серверная верификация платежа по правилам платформы. Браузер R1: тестовый магазин без реальных платежей (feature flag).
Не продаём: лут, звёзды, кубки, обход щита противника.
LiveOps: события E01–E12, сезоны (4 недели), баланс-патчи через `content_version` без релиза клиента, фичефлаги, A/B (билдера/наград).
