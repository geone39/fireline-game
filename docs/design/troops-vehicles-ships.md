## Поведение юнита (пошаговый бой, ADR-003)
Юниты атакующего **не имеют ИИ**: игрок каждый ход командует каждым (Move / Attack / Ability), см. `battle-sim.md` §5. Поле `fav` — только подсказка UI (иконка «любимая цель»). ИИ есть у юнитов **обороны** (гарнизон, герой-страж): стреляют по ближайшей цели, иначе идут к ней (`battle-sim.md` §7.4).
Особые действия: Подрывник — подрыв вплотную (×`wall_mult` по стенам, сплэш), погибает; Диверсант — `jam` вплотную к обороне; Медик/Ремонт — `heal` союзника в дальности; БТР/десантный катер — `unload`; Рейдер — самый подвижный; Дрон — летит над стенами; Герой — как юнит + способность по кулдауну в ходах.

## Масштаб армии
Лагеря: 20 housing × (1..4 лагеря) → на HQ10 — ~280 housing. Скорость обучения: казармы работают параллельно; зарядка очереди бесплатна, ускорение за gems. «Армия-бродяга»: можно держать армию готовой навсегда (не «портится»).
Смерть юнитов в бою: теряются навсегда (кроме медика-ресьюма: нет). Герои не теряются (отдых N часов).

## Идеи для дальнейшего развития (из задачи «во все стороны»)
Вторичные навыки (перк на юнит: +25% к стенам / + дистанция), ветвление исследований (Specialist vs Mass), «элитные» версии юнитов (скин + 1 свойство) за alloy; «одноразовые наёмники» за gems (ограничение 1/бой).
