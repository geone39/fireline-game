## Поведение юнита (пошаговый бой, ADR-003)
Юниты атакующего **не имеют ИИ**: игрок каждый ход командует каждым (Move / Attack / Ability), см. `battle-sim.md` §5. Поле `fav` — только подсказка UI (иконка «любимая цель»). ИИ есть у юнитов **обороны** (гарнизон, герой-страж): стреляют по ближайшей цели, иначе идут к ней (`battle-sim.md` §7.4).
Особые действия: Подрывник — подрыв вплотную (×`wall_mult` по стенам, сплэш), погибает; Диверсант — `jam` вплотную к обороне; Медик/Ремонт — `heal` союзника в дальности; БТР/десантный катер — `unload`; Рейдер — самый подвижный; Дрон — летит над стенами; Герой — как юнит + способность по кулдауну в ходах.

## Уровни юнитов (DESIGN-3, решение владельца OQ-QA2-LEVELS)
Уровень типа юнита (и техники, кораблей, заклинаний) = **максимум `to_level` среди выполненных узлов лаборатории** (`content/research.yaml`), 1 без узлов. Уровень — свойство типа, а не экземпляра: новое исследование усиливает **всех** юнитов этого типа (обученных ранее тоже) со следующего формирования `Army`; уже начатый бой уровни не меняет. Статы по уровню — `battle-sim.md` §3.2 (`level_growth` в `troops.yaml`). Клиент уровень не присылает — сервер подставляет его в `Army`. Подробно: `army-lab.md` §2.

## Масштаб армии (housing)
Три пула вместимости: **лагеря** (`b_camp`) — пехота и дроны (`INF`, `AIR`); **гараж** (`b_garage`) — техника и корабли (`VEH`, `SEA`); **Центр поддержки** (`b_support_bay`) — заклинания. Вместимость здания задаётся *по уровням* в `content/buildings.yaml` (`capacity_by_level`); сумма по зданиям × перк лаборатории `army_housing_pct`; ориентир «4 лагеря → ~280 housing к HQ10» остаётся целью баланса (числа решает balance). Герой housing не занимает. В пул входят обученные, стоящие в очередях и находящиеся в рейде юниты.
Обучение: у каждого производящего здания (казарма, завод, верфь, Центр поддержки) своя очередь; здание обучает одного юнита за раз, N зданий — параллельно; ресурсы списываются при постановке (отмена возвращает часть), ускорение за gems — общая формула `ceil(hours^0.8 × 4)`; заказ, не помещающийся в пул, отклоняется целиком. «Армия-бродяга»: армию можно держать готовой навсегда (не «портится», без содержания). Подробно: `army-lab.md` §3–§5.
Смерть юнитов в бою: теряются навсегда (медика-ресьюма нет); выжившие и неиспользованные заклинания возвращаются в запас. Герои не теряются (отдых N часов).

## Идеи для дальнейшего развития (из задачи «во все стороны»)
Вторичные навыки (перк на юнит: +25% к стенам / + дистанция), ветвление исследований (Specialist vs Mass), «элитные» версии юнитов (скин + 1 свойство) за alloy; «одноразовые наёмники» за gems (ограничение 1/бой).
