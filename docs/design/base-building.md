# База и строительство
**Сетка:** 44×44 тайла, зона построек 40×40 (4 тайла «кайма» вокруг — зона развёртывания атакующего). Регион «береговая карта» имеет водяные тайлы (верфь/береговые батареи только там). Выбор карты при создании: Равнина / Береговая / Каньон (влияет только на оформление и верфь).
**Редактор:** drag-n-drop, поворот (для 2×N), подсветка охвата (радиус огня выбранной обороны, мёртвая зона), «симуляция атаки» (запустить бота на свою базу — бесплатно, не влияет на кубки) — главный инструмент обучения.
**Правила размещения:** не пересекаются; нельзя полностью замкнуть штаб непрерывной *неразрушаемой* стеной (стены всегда разрушаемы — поэтому нет запрета); лимит `max_count_by_hq`; бункер/эсминец и т.п. по HQ.
**Строительство:** билдеры (2→5) параллельны; таймеры серверные; ускорение за gems: `cost = ceil(hours_left^0.8 × 4)`; отмена возвращает 50%.
**Улучшение штаба:** требует все «ключевые» здания текущего уровня ≥ L−1 (мягкий gate, чтобы не обходить дизайн).
**Сбор ресурсов:** нажатием (или авто-сбор в лагере с апгрейдом L5). Offline-накопление ограничено 50% хранилища сборщика (возвращайтесь 2–3 раза в сутки).
**Препятствия:** периодически вырастают (камни/обломки), очистка = мелкая награда + ощущение «живой» базы.
**Структура защиты (рекомендации игроку в подсказках):** ядро (штаб+склады) → кольцо стен → пулемёты по кругу → миномёты внутри → ловушки на «естественных путях» → приманка снаружи. Анти-метовые приёмы: «пустышки» (дешёвые здания снаружи, отвлекающие рейдеров и ловящие время).
