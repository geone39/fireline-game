# UX, туториал, вовлечение
## Экраны
Base (главный) · Raid search/preview · Army select · Battle HUD · Result · Defence log · Lab · Shop · Campaign map · Heroes · Settings · Leaderboard.
## Первые 10 минут
1. 30 с: ведущий персонаж, первое здание. 2. Сбор ресурсов. 3. Постройка казармы (мгновенная). 4. Обучение 5 стрелков (мгновенно). 5. Первый бой в кампании (этап 1: 1 здание). 6. Улучшение штаба до 2. 7. Первая оборона (пулемёт). 8. Первый PvP-рейд против «тренировочной» базы, потом реальной. Конверсия цель: ≥70% проходят шаги 1–6.
## Вовлечение
Ежедневные задания (3), награда за 3 захода (каждый день), «пока вас не было» (отчёт защит), уведомление о постройке/рейде, события, сезонные лиги. Без агрессивных механик: нет «потеряй всё», нет принуждающих таймеров.
## Доступность и локализация
ru/en, масштаб текста, цветовая безопасность, управление: касание/мышь/клавиатура-ярлыки, обучение без текстовых стен.
