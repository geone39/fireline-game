# UX, туториал, вовлечение
## Экраны
Base (главный) · Raid search/preview · Army (обучение: пулы housing, очереди по зданиям) · Army select (состав боя) · Battle HUD · Result · Defence log · Lab (дерево узлов, одно исследование за раз) · Shop · Campaign map · Heroes · Settings · Leaderboard. Правила Army/Lab — `army-lab.md`.
## Первые 10 минут
1. 30 с: ведущий персонаж, первое здание. 2. Сбор ресурсов. 3. Постройка казармы (мгновенная; лагерь уже стоит на старте — без него некуда обучать). 4. Обучение 5 стрелков (мгновенно: первый заказ армии завершается бесплатным туториальным ускорением, OQ-E6; армия новичка не выдаётся автоматически). 5. Первый бой в кампании (этап 1: 1 здание) — идёт этими 5 стрелками. 6. Улучшение штаба до 2 (открывает лабораторию; подсказка про первое исследование стрелка, без бесплатного ускорения). 7. Первая оборона (пулемёт). 8. Первый PvP-рейд против «тренировочной» базы, потом реальной (экран выбора армии: пресет «вся армия»). Конверсия цель: ≥70% проходят шаги 1–6.
## Вовлечение
Ежедневные задания (3), награда за 3 захода (каждый день), «пока вас не было» (отчёт защит), уведомление о постройке/рейде, события, сезонные лиги. Без агрессивных механик: нет «потеряй всё», нет принуждающих таймеров.
## Доступность и локализация
ru/en, масштаб текста, цветовая безопасность, управление: касание/мышь/клавиатура-ярлыки, обучение без текстовых стен.
