# Оборона
Числа: `content/defences.yaml`.
## Принципы
1. **Нет «абсолютной» защиты** — каждая оборона решаема набором юнитов/приёмов (ПВО против дронов, мины против рейдеров, ПТ против техники). Баланс смотрит на win-rate ≥35% самого слабого и ≤65% самого сильного состава против эталонных баз HQ-уровня.
2. **Заборы и проволока — не просто HP.** Забор блокирует; проволока замедляет и ранит; вместе они создают *зону убийства*: рейдеры вязнут перед пулемётами.
3. **Гарнизон бункера** выходит и сражается; пополняется из `b_defense_barracks` бесплатно между боями.
4. **Скрытые ловушки** (мины, пружины) видны только радару; радар открывает их атакующему → ценность информации.
5. **Помехи** снижают эффективность поддержки врага, но не отключают её совсем.
6. **Береговые карты:** береговая батарея, ПТ-пушка и мины на мелководье против флота; корабли обороны (патрульный катер) — часть снимка.
## Типовые шаблоны баз (для ботов и туториала)
`turtle` (всё в кольце стен), `spread` (разрежено, сложно покрыть), `kill_zone` (длинный проход к штабу), `bait` (приманка снаружи + ядро скрыто).
## Что придумать дальше
Адаптивная защита (одна секретная «передвижная» стена из 3, меняет проходы раз в сутки), огнемётные ловушки с перегревом, «счётчики» дымовых завес, зоны минирования по сезонным событиям.
