# Боевое ядро (sim) — спецификация
## Мир
Сетка 44×44 тайла, fixed-point (1 тайл=1000). Тик = 100 мс. До 120 юнитов + 150 построек одновременно. Pathfinding: A* на сетке 0.5 тайла с кэшем «карты проходимости»; перепланировка раз в 5 тиков или при разрушении стены. Стабильный порядок: сущности по `entity_id`, ничья — по id.
## Урон
`D = floor(dps × tickSec × mult_vs_class(target) × level_mult)`; интегрально: dps хранится как millidmg/tick. Покрытие/броня: `armor_pct` 0–60% снижает урон. Splash: радиус в тайлах, урон × (1 − dist/r×0.4). Стены: подрывник ×40; огнемёт ×1.5 vs wire.
## Цели обороны
По умолчанию — ближайшая в радиусе; приоритеты: `vs` класс → ближайший по пути к штабу → самый раненный. Мин. дальность исключает близкие цели. Перегрев (flame_trap) — 6 с огонь, 4 с остывание.
## Ввод
`Command{Tick,Op,ID,Pos}`; допускается только Deploy в зоне, Cast в пределах карты, HeroAbility с кулдауном. Недопустимые команды отклоняются идентично на сервере и клиенте (в Result.rejected).
## Результат
Звёзды, % разрушения, HQ, использованные тики, LootBasis, StateHash (xxhash64 по сортированному состоянию).
## Тесты
Golden: `testdata/replays/G01..` из `content` (бои на эталонных базах HQ1…HQ10), property «определён», фазз команд, бенчмарк ≥ 5000 тиков/с на CI. 
## Альтернативный планировщик
`Scheduler=Turns`: тот же мир; атакующий выпускает юниты по одному за «ход», затем N тиков (=2 с) пассивного исполнения. Реализуется как обёртка над Run — выбор в OQ-1.
