# AGENTS.md — правила для любого агента/разработчика

1. **Один агент = один модуль.** Модули в `modules/`. Правишь только файлы, перечисленные в `OWNS` своего `modules/<m>/AGENT.md`. Чужое — только через issue/PR в чужой модуль или запрос изменения контракта.
2. **Контракт важнее реализации.** Публичные границы: `CONTRACT.md` модуля + схемы в `content/schema/` + `docs/03-api.md`. Меняешь контракт → отдельный PR с пометкой `contract-change` и правкой всех потребителей-заглушек.
3. **Данные отдельно от кода.** Числа (hp, цены, время) живут только в `content/*.yaml`. В коде запрещены «магические» игровые константы.
4. **Детерминизм sim.** В `sim/`: без `time`, `math/rand`, `float`, итерации по `map` в логике. Нарушение = блокирующее замечание.
5. **Сервер авторитарен.** Клиент ничего не решает про ресурсы/награды; он отправляет команды, сервер проверяет и пересчитывает бой.
6. **Каждый PR:** (а) одна цель, (б) тесты/golden, (в) `make check` зелёный, (г) обновлён `CHANGELOG` модуля, (д) для баланса — приложен вывод `tools/econ_sim.py`.
7. **Ветки:** `main` защищена; работа в `feat/<module>-<short>`; коммиты `type(module): summary` (feat, fix, data, docs, test, refactor, chore).
8. **Неясно — не угадывай:** создай запись в `docs/open-questions.md` и продолжай с самым безопасным допущением, пометив `ASSUMPTION:`.
9. **Определение готовности (DoD)** — в `modules/<m>/AGENT.md`.
